# 「字里行间」页面设计文档

> 《燕食记》网站新增子页面：精选书中段落 + 文学随笔体书评，用葛亮的文字本身勾起读者对本书的兴趣。

日期：2026-06-06

---

## 1. 定位与目标

新增第四个子页面，陈列《燕食记》中最动人的段落，每段配一则文学随笔体书评。

- **目的**：让读过的人重温，未读的人"读着读着就想买书"。核心是展示精彩文字，提升对本书的兴趣。
- **与其他页的差异**：人物页、美食页是"条目多而短"，用卡片网格 + 弹窗；本页是"条目少而长"，用沉浸式长卷阅读。

## 2. 文件与导航

- 文件名：`reading.html`
- 导航标签：**字里行间**
- 四页导航顺序：欢迎（`index.html`）/ 人物关系（`characters.html`）/ 书中美食（`cuisine.html`）/ 字里行间（`reading.html`）
- 需在 `index.html`、`characters.html`、`cuisine.html`、`reading.html` 四个页面的顶部导航中统一加入"字里行间"项。

## 3. 阅读形态

长卷·文学杂志式，整页竖向滚动沉浸阅读。无 tab 切换、无弹窗，段落顺着主题分区自上而下铺开。

## 4. 主题分区

竖向分区，各带分区小标题（二字凝练风）。当前三区：

| 分区 | 主题 | 示例段落 |
|---|---|---|
| **承味** | 手艺与传承 | 片段1 · 莲蓉月饼（河川守智被一只莲蓉月饼震动，勾起童年与失传双蓉月饼传说）；片段2 · 辣酱月饼（戴明义为柳素娥烧本帮家常、做独一份辣酱月饼） |
| **古韵** | 古意雅致 | 片段3 · 道观拉弓（上阕第九章《烽火硝烟》，段老板拉开六百斤大弓，读来如武侠） |
| **入微** | 人物细节与心情的细致描写 | 待补段落 |

- "烟火/离合（流转）"等分区暂不设立，待有对应段落再扩展，避免空区。
- **入微** 区暂无段落，先建好分区框架，内容后补。

## 5. 单条段落结构

每个段落条目从上到下：

1. **出处小标** —— 如"上阕·第九章 烽火硝烟"。JetBrains Mono 字体 + 暖金色，与全站小标签一致。
2. **点睛引语（钩子）** —— 从原文抽取一句最抓人的话，大字号衬线、赭红色单独亮出，先勾住读者再往下读。
   - 例：片段1 取"第一次，他被一款看似普通的莲蓉月饼所震动"。
3. **原文段落** —— 衬线正文（Noto Serif SC）铺开，舒朗行距，为条目主体。
4. **书评** —— 文学随笔体，用左侧暖金竖线 + 浅底色框与原文区分，形似"编者按"。

不设关联跳转链接，不设主题标签（分区大标题已表明主题）。

## 6. 书评文体（统一规范）

**甲 · 文学随笔体**：第三人称、克制典雅，像精选集的编者按或名家导读。点出文字的妙处与情感/文化分量，引导兴趣，不口语化、不过度个人化。

示例（片段1）：

> 一只看似普通的莲蓉月饼，写的却是味觉如何唤回童年、手艺如何完成传承。葛亮不正面写阿响怎样苦练，只借一个异乡人舌尖上那一下"震动"——齿颊间忽然涌出的津液，把多年遍尝南北名点的舌头，一举拉回到记忆最深处。失传的双蓉、无踪的大按师傅、默然的赵守智，三条暗线在一口饼里交汇。所谓传承，原来不必声张，自有人在等待，也自有人没有辜负这份等待。

## 7. 视觉与技术

- **沿用全站体系**：暖色 CSS 变量（paper / ink / gold / rust / green / crimson）、字体组合（ZCOOL XiaoWei + Noto Serif SC + JetBrains Mono）、顶部 sticky 导航、右下角背景音乐播放器（跨页续播）。
- **技术栈**：纯 HTML5 + CSS3 + 原生 JavaScript，无框架、无构建步骤。
- **数据驱动**：段落内容用 JS 数组（含 分区 / 出处 / 点睛引语 / 原文 / 书评 字段）渲染，便于后续增删段落。
- **适配**：桌面优先，移动端可读；动效在 `prefers-reduced-motion` 下静止。

## 8. 内容来源工作流

- 用户提供段落 → 我撰写书评（统一甲·文学随笔体）。
- 或用户给方向 → 我爬取网络候选段落/书评 → 用户筛选。
- 书评统一文体；引用原文严格控制，遵循全站"关于引文"的克制原则。

- 古韵：片段3 · 道观拉弓
- 入微：暂无（先建分区框架，后补）
