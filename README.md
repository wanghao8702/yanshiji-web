# 燕食记网站 · YANSHIJI-WEB

> 把葛亮的长篇小说《燕食记》「打开」——沿人物与菜品两条线索，走进岭南饮食的文化空间。

🌐 **线上地址**：https://yanshiji-web.vercel.app

《燕食记》是葛亮以岭南饮食为载体写就的长篇小说。书中两代厨人的命运、近百道粤菜与本帮菜、广府—香港—上海三地的流转，构成一座可以「被走进」的文化空间。本站把这本书可视化：读过的人可当作延伸阅读的地图，未读的人可由此入席。

---

## 快速上手：把项目保存到本地运行

> **适合完全没有编程经验的读者。** 整个过程不需要安装任何软件（除了浏览器），大约 3 分钟即可完成。

### 方法一：直接下载 ZIP（最简单）

1. 打开本项目的 GitHub 页面
2. 点击右上角绿色按钮 **`Code`** → 选择 **`Download ZIP`**
3. 把下载的 `.zip` 文件解压到你想放的文件夹
4. 进入解压后的文件夹，双击 **`index.html`**，用浏览器打开即可

> **提示**：如果页面字体显示异常，说明你的网络无法访问 Google Fonts，这不影响正常浏览，内容完整可读。

---

### 方法二：用 Git 克隆（方便后续同步更新）

如果你希望以后能一键拉取最新内容，可以用 Git 克隆项目。

**第一步：安装 Git**（如果还没装）

- Windows：前往 https://git-scm.com/download/win 下载安装，一路点「下一步」即可
- Mac：打开「终端」，输入 `git --version`，系统会提示你安装

**第二步：克隆项目**

打开终端（Windows 叫「命令提示符」或「PowerShell」，Mac 叫「终端」），输入：

```bash
git clone https://github.com/你的用户名/yanshiji-web.git
```

> 把 `你的用户名` 替换成实际的 GitHub 用户名。

**第三步：打开网站**

```bash
cd yanshiji-web
```

然后双击文件夹里的 `index.html`，用浏览器打开即可。

**以后想更新到最新版本**，进入文件夹后运行：

```bash
git pull
```

---

### 方法三：本地静态服务器（解决某些浏览器的限制）

部分浏览器在直接双击打开 HTML 文件时，会限制某些功能（如字体加载、音乐播放）。如果遇到问题，可以起一个本地服务器：

**用 Python（大多数电脑自带）：**

```bash
# 进入项目文件夹
cd yanshiji-web

# Python 3（推荐）
python -m http.server 8080

# Python 2（较旧系统）
python -m SimpleHTTPServer 8080
```

然后在浏览器地址栏输入 `http://localhost:8080` 即可访问。

按 `Ctrl + C` 可停止服务器。

## 设计与技术

- **视觉调性**：暖色调——奶油纸感暖米底色，赭红 / 暖金 / 墨绿点缀，墨棕主文字。「文学杂志 × 岭南老味」
- **字体**：ZCOOL XiaoWei（标题）+ Noto Serif SC（正文）+ JetBrains Mono（英文 / 数字），Google Fonts CDN
- **插画与背景**：全部 SVG 自绘（满洲窗、蒸笼、广彩纹样、菜品），无外部图片依赖、无版权风险
- **技术栈**：纯 HTML5 + CSS3 + 原生 JavaScript，无框架、无构建步骤，单文件即可离线打开
- **适配**：桌面优先，移动端可用；动效在 `prefers-reduced-motion` 下自动静止

## 数据来源与说明

人物与菜品资料综合自网络整理、专业书评与百科词条，**仍可能存在偏差，以书中实际为准**。书中部分人物关系是葛亮**故意半隐半显**的留白（如司徒灵思的父亲、九太太青湘的死因），站内以 ⚠️ 标注并说明——这是文学技法，并非数据缺失。引用原文严格控制长度，详情多为意译与概括。欢迎读者校正反馈。
